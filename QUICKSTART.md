## Getting Started

### 1. Test Locally
```bash
# On Windows, simply open in browser:
Start C:\xampp\htdocs\tayyab\index.html

# Or visit:
http://localhost/tayyab
```

### 2. Customize Your Content

**Update Hero Section:**
- Edit `index.html`, find hero section
- Change heading, subtitle, description
- Update contact phone number

**Update Projects:**
- Find project cards in HTML
- Change project names, descriptions, technologies
- Update links to your projects

**Update Skills:**
- Find skill categories section
- Add/remove skills as needed
- Adjust skill percentages

**Update Experience:**
- Edit timeline items
- Add job titles, companies, dates
- Update job descriptions

**Update Contact:**
- Change email address
- Change phone number
- Update social media links

### 3. Customize Colors (5 minutes!)

Open `styles.css`, find this at the top:

```css
:root {
    --primary-color: #00d4ff;        /* Change this color */
    --secondary-color: #667eea;      /* And this one */
    --accent-color: #00ffff;         /* And this one */
```

**Popular color combinations to try:**
- Pink & Purple: `#ff006e`, `#8338ec`, `#fb5607`
- Ocean Blue: `#0091ad`, `#00b4d8`, `#00d9ff`
- Green: `#00ff9a`, `#6bcf7f`, `#00ff88`

### 4. Test Responsiveness

**Desktop (1200px+):**
- Open in browser, view normally

**Tablet (768px-1024px):**
- Resize browser to 900px wide
- Or use DevTools (F12) responsive mode

**Mobile (480px):**
- Resize to 375px wide
- Test hamburger menu
- Check form submission

### 5. Deploy

1. Upload all files to your web host via FTP
2. Ensure `send-email.php` has correct credentials
3. Test form submission on live server
4. Share your portfolio URL!

## Common Customizations
